# Weather App

A simple Weather Application built using Python, Tkinter, and the OpenWeather API. The application provides real-time weather information, including weather conditions, descriptions, and temperature for selected locations through an easy-to-use graphical interface. Its still in prototype phase. Yet to be Developed.


## Features

* Real-time weather data retrieval
* User-friendly Tkinter GUI
* Weather condition display
* Temperature information
* OpenWeather API integration

## Technologies Used

* Python
* Tkinter
* Requests
* OpenWeather API
